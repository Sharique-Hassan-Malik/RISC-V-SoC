# Architecture

## Overview

A 4-voice polyphonic synthesiser implemented entirely in Verilog with no
soft-core CPU anywhere in the design.  Every block — oscillators, envelopes,
filter, MIDI receiver, voice allocator, mixer and DAC — is a synthesisable
RTL module connected by wires.  The design targets the Lattice iCEstick
evaluation board (iCE40HX1K-TQ144) with a 12 MHz oscillator, MIDI input via
an optocoupler and audio output via a first-order sigma-delta DAC driving an
RC low-pass filter.

## Module Descriptions

### `sample_clk.v`

Divides the 12 MHz master clock by `CLK_HZ / SAMPLE_RATE = 250` to produce
a single-cycle `sample_tick` pulse at 48 kHz.  All DSP blocks gate their
state registers on `sample_tick` to advance at the audio sample rate.

### `midi_rx.v`

A two-stage pipeline:

**UART receiver** — oversamples the RX input at `CLK_HZ / MIDI_BAUD = 384`
cycles per bit.  Synchronises the async input through two flip-flops, detects
the start bit by a falling edge, waits half a bit period to centre-sample,
then reads 8 data bits at full-bit intervals.  Framing is validated by checking
the stop bit.

**Message assembler** — three-state machine (status / data1 / data2).  Handles
running status: a second pair of data bytes re-uses the last status byte.
Emits `msg_valid` for one clock when a complete Note On, Note Off or Control
Change message is assembled.  System Exclusive and real-time bytes are discarded.

### `voice_alloc.v`

Maintains four voice slots.  On Note On, searches for a free slot; if none is
available, steals the slot with the highest age counter (the voice that has
been active the longest).  On Note Off, clears the gate of the matching slot.
Age counters increment every clock cycle; the oldest voice is reliably
identified even under concurrent note events.

### `note_to_phase.v`

A 128-entry synchronous ROM (maps to one 4 Kbit block RAM on iCE40).  Entry `n`
holds the 32-bit DDS phase increment for MIDI note `n` at 48 kHz:

```
phase_inc[n] = round(440 × 2^((n−69)/12) / 48000 × 2^32)
```

For A4 (note 69): `phase_inc = round(440/48000 × 2^32) ≈ 39 321 855`.

### `dds_osc.v`

A 32-bit DDS phase accumulator and 1024-point Q15 sine ROM (iCE40 block RAM).
On each `sample_tick` the accumulator advances by `phase_inc`; the top 10 bits
address the ROM.  The ROM is initialised from `sine1024_q15.hex` generated by
`gen_hex.py`.

DDS frequency resolution: `48000 / 2^32 ≈ 11.2 µHz` — inaudible pitch error.

### `adsr_env.v`

A five-state machine (IDLE → ATTACK → DECAY → SUSTAIN → RELEASE → IDLE) clocked
by the master clock, advancing the 16-bit amplitude register on every master
clock cycle by the configured rate.  The ADSR rates come from `cc_store.v`.

A 17-bit extended accumulator detects overflow (attack) and underflow (decay,
release) without needing a comparator wider than 17 bits.  The output is a
16-bit unsigned value in [0, 65535].

### `q15_mul.v`

Signed Q15 × unsigned Q16 → signed Q15 multiply.  Infers a single DSP
multiplier on iCE40 (`SB_MAC16` or equivalent).  Applies the envelope
amplitude to the oscillator sample.

### `biquad_df1.v`

Direct-Form I second-order IIR filter.  Five multiplications per sample
executed combinationally (mapped to five `SB_MAC16` units or equivalent).
The 32-bit accumulator is arithmetically shifted right by 15 (Q15 coefficients)
and saturated to 16-bit signed output.  The `COEFF_SHIFT` parameter accommodates
coefficients with |gain| > 1.

**Coefficient derivation** (bilinear transform, Butterworth LP):
```
K     = tan(π × fc / Fs)
a0    = 1 + K/Q + K²
b0    = K²/a0      b1 = 2b0      b2 = b0
a1_bq = 2(K²−1)/a0               a2_bq = (1−K/Q+K²)/a0
```

At fc = 2 kHz, Q = 0.707, Fs = 48 kHz the Q15 values are:
```
b0 = 0x0264   b1 = 0x04C8   b2 = 0x0264
a1 = 0x2662   a2 = 0x1AEB
```

Run `python3 gen_hex.py --fc <fc_hz> --q <q_val>` for other cutoff frequencies.

### `voice_mixer.v`

Pure combinational adder tree.  Accumulates all 4 voice samples in a 20-bit
signed accumulator (16 + log2(4) = 18 bits minimum, rounded to 20 for margin)
then arithmetic-right-shifts by 2 (divides by 4) and saturates to 16-bit.

### `pwm_dac.v`

First-order sigma-delta (noise shaping) modulator running at the 12 MHz master
clock (oversampling ratio 250).  Converts offset-binary sample to a 1-bit PDM
stream.  At 250× OSR the theoretical SNR is approximately:

```
SNR ≈ 6.02 × 16 + 1.76 − 5.17 + 30 log10(250) ≈ 50 dB
```

In practice the first-order loop gives only 9 dB per octave of noise-shaping
improvement — a higher-order modulator or an external I2S DAC is recommended
for production.

### `cc_store.v`

Maps incoming CC numbers to named registers and presents them as 16-bit rate
values to the ADSR blocks.  The CC-to-rate conversion is:

```
rate = (cc_val + 1) × 512
```

At 48 kHz with 16-bit envelope arithmetic, this gives:
- CC value 0 → rate 512 → full sweep in 65535/512 = 128 samples = 2.7 ms
- CC value 127 → rate 65536 → instant step

## Resource Estimate (iCE40HX1K)

| Block | LUTs | Block RAMs | DSP multipliers |
|---|---|---|---|
| midi_rx | ~80 | 0 | 0 |
| voice_alloc | ~40 | 0 | 0 |
| sample_clk | ~10 | 0 | 0 |
| note_to_phase × 4 | 0 | 4 (shared) | 0 |
| dds_osc × 4 | ~20 | 4 (sine ROM) | 0 |
| adsr_env × 4 | ~100 | 0 | 0 |
| q15_mul × 4 | ~20 | 0 | 4 |
| biquad_df1 | ~30 | 0 | 5 |
| voice_mixer | ~20 | 0 | 0 |
| pwm_dac | ~20 | 0 | 0 |
| cc_store | ~30 | 0 | 0 |
| **Total** | **~370** | **8** | **9** |

The iCE40HX1K has 1280 LUTs, 16 block RAMs and no dedicated hardware DSP.
On iCE40 the DSP multipliers are inferred from LUT carry chains (about 80 LUTs
each), raising the realistic total to approximately 750 LUTs — fits comfortably
within the 1280-LUT device.

## Building

```bash
# Generate ROM HEX files (required before synthesis).
python3 sim/gen_hex.py

# Synthesise (Yosys + nextpnr).
yosys -p "synth_ice40 -top synth_top -json synth_top.json" \
      rtl/synth_top.v rtl/dds_osc.v rtl/adsr_env.v rtl/q15_mul.v \
      rtl/biquad_df1.v rtl/midi_rx.v rtl/voice_alloc.v \
      rtl/note_to_phase.v rtl/sample_clk.v rtl/voice_mixer.v \
      rtl/pwm_dac.v rtl/cc_store.v

nextpnr-ice40 --hx1k --package tq144 \
              --json synth_top.json --pcf rtl/synth_top.pcf \
              --asc synth_top.asc

icepack synth_top.asc synth_top.bin
iceprog synth_top.bin
```

## Simulation

```bash
# Generate ROM HEX files.
python3 sim/gen_hex.py

# Compile testbench.
iverilog -g2012 -o tb_synth \
    sim/tb_synth.v rtl/synth_top.v rtl/dds_osc.v rtl/adsr_env.v \
    rtl/q15_mul.v rtl/biquad_df1.v rtl/midi_rx.v rtl/voice_alloc.v \
    rtl/note_to_phase.v rtl/sample_clk.v rtl/voice_mixer.v \
    rtl/pwm_dac.v rtl/cc_store.v

# Run simulation (~30 s for 500 ms of audio).
vvp tb_synth

# Decode PDM output to WAV.
python3 sim/decode_pdm.py pdm_out.bin --out synth_out.wav

# View waveforms.
gtkwave tb_synth.vcd
```
